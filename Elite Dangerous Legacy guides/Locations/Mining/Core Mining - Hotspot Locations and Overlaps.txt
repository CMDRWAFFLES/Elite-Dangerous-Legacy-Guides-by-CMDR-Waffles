CORE MINING - HOTSPOT LOCATIONS AND OVERLAPS
========================================================


CORE-MINING HOTSPOT RULE
========================
Hotspot counts above are the number of named hotspots in that ring.
They do NOT mean those hotspots overlap.

For core mining, a hotspot increases the chance that a core you find contains
the hotspot's named mineral. It does not increase the number of core asteroids.
Reserve level is therefore not used as a quality ranking here.
